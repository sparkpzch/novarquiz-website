# ข้อมูล LSCVD และแผนที่รายจังหวัด: data dictionary และวัตถุประสงค์

LSCVD ในเอกสารนี้หมายถึงโรคหัวใจและหลอดเลือดที่เกี่ยวข้องกับไขมันในเลือด (หลอดเลือดแดงแข็งจากภาวะไขมันผิดปกติ หรือ ASCVD)

## วัตถุประสงค์

ข้อมูลชุดนี้ใช้ประเมินโครงการให้ความรู้และป้องกัน LSCVD ในระดับจังหวัด ไม่ได้ใช้วินิจฉัยหรือประเมินความเสี่ยงของใครเป็นรายบุคคล

1. **การเข้าถึง**: มีผู้เข้าร่วมจากจังหวัดไหนบ้าง และกี่คน
2. **ภาระปัจจัยเสี่ยง**: ความชุกของบุหรี่ ความดันสูง เบาหวาน ไขมันสูง น้ำหนักเกิน และอ้วนลงพุง
3. **Care cascade ของไขมัน**: ผู้เข้าร่วมหลุดที่ขั้นไหน ตั้งแต่การตรวจ การรู้ค่า LDL การวินิจฉัย การได้รับยา จนถึง LDL ถึงเป้า
4. **ความรู้และผลของการให้ความรู้**: คะแนนความรู้รายจังหวัด และการเปลี่ยนแปลงระหว่างคำตอบครั้งแรกกับครั้งล่าสุด
5. **จัดลำดับพื้นที่**: หาจังหวัดที่ควรเร่งคัดกรองหรือเร่งให้ความรู้ก่อน

## ข้อมูลที่เก็บ

เก็บผ่านแบบสอบถามในขั้นตอนสมัครสมาชิก และแก้ไขได้ที่หน้าโปรไฟล์ (`components/onboarding/SurveyFields.tsx`) เวอร์ชันแบบสอบถาม `2026-10-v2`

### ข้อมูลการทำแบบทดสอบ (มีอยู่แล้ว)

`user_answers` นับเฉพาะคำตอบล่าสุดของแต่ละข้อ (ต่อผู้ใช้ ต่อ session และต่อคำถาม) คำตอบที่ `utility_score > 0` ถือว่าตอบถูก ซึ่งเป็นกติกาเดียวกับ `completeSession()`

## นิยามตัวชี้วัด (`lib/analytics/lscvd.ts`)

- **ตัวหาร** ของทุก % ไม่นับคำตอบ `unknown` และ CSV จะระบุตัวหาร (base) ไว้คู่กับค่า
- **ผู้เข้าร่วม** = คนที่ยินยอมให้วิเคราะห์ (`analytics_consent`) และมีจังหวัด
- **ผู้ตอบข้อมูลสุขภาพ** = คนที่มีแถวใน `participant_health_profiles`
- **คะแนนความรู้** = ค่าเฉลี่ยของ % ตอบถูกรายคน แต่ละคนมีน้ำหนักเท่ากัน คิดเฉพาะผู้เข้าร่วมที่ตอบอย่างน้อย 1 ข้อ
- **น้ำหนักเกิน** = BMI ≥ 25 ตามเกณฑ์คนเอเชีย ใช้น้ำหนักและส่วนสูงซึ่งต้องมีความยินยอมให้วิเคราะห์ด้วย
- **อ้วนลงพุง** = รอบเอว ≥ 90 ซม. (ชาย) หรือ ≥ 80 ซม. (หญิง) คิดเฉพาะคนที่ระบุเพศชายหรือหญิง
- **จำนวนปัจจัยเสี่ยง** นับจากบุหรี่ (current), ความดันสูง, เบาหวาน, ไขมันสูง, ประวัติครอบครัว และ BMI ≥ 25 โดยคำตอบ `unknown` ไม่นับเป็นมีปัจจัยเสี่ยง
- **เสี่ยงสูง** = มีปัจจัยเสี่ยงตั้งแต่ 3 ข้อ หรือเคยเป็นกล้ามเนื้อหัวใจขาดเลือดหรือสโตรก
- **ตรวจไขมันภายใน 5 ปี** = within_1y หรือ within_5y
- **ตรวจช้าหรือไม่เคยตรวจ** = over_5y หรือ never
- **เป้า LDL (แบบประมาณ)**: ต่ำกว่า 70 สำหรับคนที่เคยเป็นโรคหัวใจหรือสโตรก หรือเป็นเบาหวาน และต่ำกว่า 100 สำหรับคนทั่วไป เป้า 55 สำหรับกลุ่มเสี่ยงสูงมากอ่านไม่ได้ เพราะช่วงค่าที่เก็บไม่ละเอียดพอ
- **Care cascade** นับในกลุ่มคนที่แพทย์บอกว่าไขมันสูง: วินิจฉัย → ได้รับยา → LDL ถึงเป้า
- **ผลการเรียนรู้** ใช้ข้อที่ตอบมากกว่า 1 ครั้ง เทียบ % ตอบถูกของคำตอบครั้งแรกกับครั้งล่าสุด

## การคุ้มครองข้อมูล

- **ซ่อนกลุ่มเล็ก (k = 1)**: ตอนนี้ตั้งไว้ที่ 1 คน คือแสดงตัวเลขทุกกลุ่มที่มีอย่างน้อย 1 คน ผู้ดูแลจึงอาจเห็นคำตอบของบุคคลเดียวได้ ซ่อนเฉพาะกลุ่มที่ไม่มีคนเลย กลไกเดิมยังอยู่ ถ้าเพิ่ม `MIN_CELL` ภายหลัง ระบบจะคำนวณตัวชี้วัดแต่ไม่ส่งออกจาก server ส่งเฉพาะจำนวนคน ใช้กับ:
  - คะแนนความรู้ (นับจากผู้เข้าร่วม)
  - ตัวชี้วัดสุขภาพ (นับจากผู้ตอบข้อมูลสุขภาพ)
  - ข้อมูลประชากร (ทั้งประเทศ รายจังหวัด รายเซสชัน และรายแบบทดสอบ)
  - ข้อมูลรายเดือน, quiz ยอดนิยม และผลการเรียนรู้ ซึ่งตัดเดือนหรือ quiz ที่มีน้อยกว่า k คนออก
- **filter เพศและอายุ** ใช้คำตอบแบบสอบถาม จึงนับเฉพาะคนที่ยินยอมให้วิเคราะห์
- **API** ใช้ได้เฉพาะ admin, ตรวจพารามิเตอร์ด้วย Zod, จำกัดจำนวนครั้งต่อบัญชี และส่ง `Cache-Control: private, no-store`
- **CSV** มีเฉพาะค่าภาพรวม ไม่มี uid ชื่อ หรือคำตอบรายคน
- **AI**: ข้อมูลแบบสอบถามและข้อมูลสุขภาพไม่ถูกส่งไปที่บริการสรุปผลด้วย AI
- **นโยบายความเป็นส่วนตัว** เวอร์ชัน `2026-10-15` อธิบายข้อมูลชุดนี้ไว้แล้ว ผู้ใช้ทุกคนจะเห็นหน้ายอมรับนโยบายใหม่ 1 ครั้ง

## filter (`ProvinceFiltersSchema`)

| key | ความหมาย |
|---|---|
| `from`, `to` | ช่วงวันที่ตอบ (วันตามเวลาไทย) เมื่อใช้ filter นี้ จะนับเฉพาะคนที่มีคำตอบในช่วงนั้น |
| `quiz` | นับเฉพาะคำตอบและคนที่เล่น quiz นี้ |
| `age` | under18 / 18_29 / 30_44 / 45_59 / 60plus |
| `gender` | female / male / other |

ค่าอื่นใน URL ของหน้าแผนที่ เช่น `color`, `scale`, `region`, `min`, `top` และ `sel` ใช้เฉพาะในเบราว์เซอร์ ไม่ถูกส่งไป API

## แผนที่

- ขอบเขตจังหวัดมาจาก geoBoundaries THA ADM1 (gbHumanitarian) ต้นทางคือกรมแผนที่ทหารผ่าน HDX สัญญาอนุญาต CC BY 3.0 IGO มีเครดิตใต้แผนที่แล้ว
- สร้างไฟล์แผนที่ใหม่ได้ด้วยคำสั่ง `tsx scripts/maps/build-thailand-map.ts <geoBoundaries-THA-ADM1_simplified.geojson>` ผลลัพธ์อยู่ที่ `lib/maps/thailand-provinces.ts`
- สีแผนที่ใช้ 5 ระดับแบบ quantile (สลับเป็นช่วงเท่ากันได้) ชุดสีแยก light/dark และผ่านการตรวจแบบ ordinal

## ข้อจำกัด

- ข้อมูลสุขภาพทั้งหมดผู้ใช้ตอบเอง ไม่ได้มาจากผลตรวจ
- ผู้ใช้เป็นคนเลือกเข้าร่วมเอง จึงไม่ได้เป็นตัวแทนประชากรของจังหวัด
- การแสดงเป็นสัดส่วนต่อประชากรยังไม่ได้ทำ
- คำตอบ "ไม่ทราบ" ถูกนับว่าไม่มีปัจจัยเสี่ยงในการนับจำนวนปัจจัย ตัวเลขนี้จึงอาจต่ำกว่าความจริง
- หลังเปลี่ยนเวอร์ชันแบบสอบถาม ผู้ใช้เดิมจะไม่ถูกนับจนกว่าจะตอบเวอร์ชันใหม่
