# UI wording

Use short, factual wording in Thai and English. Name the data or action. Keep labels consistent between pages. Buttons describe actions; error messages describe the problem and the next action. Avoid motivational slogans, exaggerated praise and technical terms in participant-facing text.

| Use | Avoid |
| --- | --- |
| ข้อมูลผู้เข้าร่วม / Participant information | ผู้เรียนของเราเป็นใคร / Who is learning? |
| สรุปผลแบบทดสอบ / Quiz summary | สรุปสำหรับคุณ / Your personal recap |
| คะแนนรายหัวข้อ / Scores by topic | Topic understanding breakdown |
| ดูคำอธิบาย / View explanation | Help me understand |
| ตอบถูกทุกข้อ / All answers correct | Generic praise |
| เปรียบเทียบผล / Compare results | Cross-cohort clinical analysis |

Preserve consent choices, review status and medical disclaimers. AI summaries name the quiz subject and actual selected answers. A perfect result is acknowledged plainly, followed by a specific idea from the explanations. Existing reviewed summaries are not rewritten automatically.

History displays five equal-width score intervals from 0 to 100%. The final interval includes 100%; other intervals exclude their upper bound. Counts represent topics, not users. Topics without scores are excluded and reported separately.

References consulted:
- [GOV.UK: Writing for user interfaces](https://www.gov.uk/service-manual/design/writing-for-user-interfaces): short, direct copy and descriptive headings.
- [GOV.UK: Buttons](https://design-system.service.gov.uk/components/button/): action labels and sentence case.
- [Atlassian: Voice and tone](https://atlassian.design/foundations/content/voice-tone/): clear, accurate wording suited to the situation.
- [Atlassian: Style, grammar and punctuation](https://atlassian.design/foundations/content/language-and-grammar): consistent, readable terminology.
